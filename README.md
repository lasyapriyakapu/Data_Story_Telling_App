# 🚢 Titanic Data Storytelling App

## 📌 Project Overview
This project analyzes the Titanic dataset and presents meaningful insights using data storytelling techniques.

It helps understand how different factors like gender, age, passenger class, and fare affected survival chances.

---

## 📊 Features
- Dataset Introduction
- Data Cleaning
- Exploratory Data Analysis (EDA)
- 5 Interactive Visualizations
- Insights and Observations
- Final Conclusion

---

## 📁 Dataset Used
Titanic Dataset from Kaggle / Open Source:
https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv

---

## 🛠️ Technologies Used
- Python
- Pandas
- Streamlit
- Plotly

---

## 📈 Visualizations
1. Survival Count
2. Gender vs Survival
3. Passenger Class vs Survival
4. Age Distribution
5. Fare Distribution
